# Learning ODIN with conways game of life

I think Odin might be my new favorite programming language. Only programmed for a week or so with it but so far I'm impressed, I like it a lot 
more than Zig. I love the vendor library that comes with bindings for the essential programs and that it was so easy to get started and build something 
with it. The syntax being almost identical to Go is a huge bonus.

It's amazing what computers can do now, but there is something so satisfying about figuring out patterns and seeing it actually reflected in the UI.

Hand's down one my favorite parts of programming. It's easy to forget this sometimes, I guess why recreational things like learning a new programming 
language is so vital.
